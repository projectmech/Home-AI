## M1b — install from GitHub and web-first setup [IN PROGRESS — items 1-5 written; users, updates UI, backups, recovery outstanding]
Full requirements: `prompts/06-GITHUB-INSTALL-AND-WEB-SETUP.md`. The user asked for this before any integration.
1. Setup token hardening: issued by a local CLI command, stored hashed with an expiry, rate-limited, not regenerated by a restart; documented recovery command.
2. In-process HTTPS listener with an install-time certificate and printed fingerprint (new ADR superseding the proxy decision in ADR 0001).
3. Release workflow: tagged builds of the baseline binary plus `web/dist`, with checksums and a signature.
4. `install.sh`, `uninstall.sh`, `update.sh`, systemd unit, config templates; installer tested in CI on Debian.
5. Setup wizard: welcome, administrator, home configuration, security, finish. Steps for AI, voice and integrations appear only as unavailable until those subsystems exist.
6. Users page, Updates and Backups sections, terminal recovery documentation.
Acceptance: prompts/06 §12. Reboot survival and real-hardware install stay NOT TESTED until run on the Mac mini.
Decided 2026-11-12: the repository stays private. The installer therefore works from a release bundle the user supplies, or a read-only token (docs/adr/0002).
